# Print Helper - 1-Click Demo Launcher Directory

This directory contains automated execution scripts to launch the complete system (Backend API, Student App, Admin Control Panel, and Desktop Print Agent) with a single click.

## How to Run
- Double-click **`run_all.bat`** (or execute `.\demo\run_all.ps1` in PowerShell).
- Four command prompt windows will automatically open up and start:
  1. **Backend API**: `http://localhost:5000`
  2. **Student App**: `http://localhost:5173` (Also exposed on local Wi-Fi IP for phone testing)
  3. **Admin App**: `http://localhost:5174` (Also exposed on local Wi-Fi IP for phone testing)
  4. **Desktop Print Agent**: Connected daemon
